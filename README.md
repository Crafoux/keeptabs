# Keep Tabs

Save all the tabs of a browser window to a file, close the window, and get
everything back later with a double-click.

> **Status:** 🚧 early development — not usable yet.

Keep Tabs is a free and open-source extension for Chromium-based browsers
(Google Chrome, Microsoft Edge, Brave…).

## Why

Too many windows open, each one a project on hold that you can't afford to
lose? Bookmarks are not made for that, and closing the window feels risky.

Keep Tabs turns a window into a file you keep wherever you want — on your
Desktop, in a project folder — and brings it back exactly as you left it.

## Planned for v1

- **Save the current window** to a file. You choose its name and location
  (the Desktop by default).
- **Restore it with a double-click:** same tabs in the same order, pinned
  tabs, tab groups (name, color, collapsed state), active tab, window size and
  position.
- **Lazy loading:** only the active tab loads right away; the others load when
  you click them. Can be turned off when saving.
- **Works without the extension too:** the session file then shows the list
  of saved links.
- **English and French.**

## Privacy

No account, no server, no tracking. Your tabs never leave your computer: they
are only written to the file you choose.
